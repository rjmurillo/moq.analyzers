# Moq1000: Sealed classes cannot be mocked

| Item     | Value   |
| -------- | ------- |
| Enabled  | True    |
| Severity | Warning |
| CodeFix  | False   |

---

Moq mocks a class by generating a subclass of it. A sealed class cannot have subclasses, so Moq cannot mock it.

To fix the violation, do one of the following:

- Introduce an interface and mock the interface instead.
- Use the real class instead of a mock.
- Remove the `sealed` modifier from the class.

## Examples of flagged code

```csharp
sealed class MyClass { }

var mock = new Mock<MyClass>(); // Moq1000: Sealed classes cannot be mocked
```

## How to fix

```csharp
class MyClass { }

var mock = new Mock<MyClass>();
```

## Suppress a warning

To suppress a single violation, add preprocessor directives to your source file
that disable and then re-enable the rule.

```csharp
#pragma warning disable Moq1000
var mock = new Mock<MyClass>(); // Moq1000: Sealed classes cannot be mocked
#pragma warning restore Moq1000
```

To disable the rule for a file, folder, or project, set its severity to `none`
in the
[configuration file](https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/configuration-files).

```ini
[*.{cs,vb}]
dotnet_diagnostic.Moq1000.severity = none
```

For more information, see
[How to suppress code analysis warnings](https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/suppress-warnings).
